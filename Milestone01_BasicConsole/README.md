# Car Rental System

## Project Idea
A console-based and eventually web-enabled Car Rental System that allows customers to browse cars, manage rentals, calculate daily totals, and securely track user-specific bookings.

---

## Milestone 01 - Basic Console Application
- **Demonstrates:** Procedural console menu, variables, loops, conditions, methods, collections (`List<T>`), basic CRUD operations (Add, List, Find, Delete), and **JSON file persistence**.
- **How to Run:**
    1. Open the solution in JetBrains Rider or Visual Studio.
    2. Set `Milestone01_BasicConsole` as the startup project.
    3. Run the application and use the console menu options (1-6).
